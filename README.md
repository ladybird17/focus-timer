# 개발자 집중 타이머
집중력을 끌어모으고 싶은 개발자를 위한 뽀모도로 타이머

## 특징
1. 업무 모드/공부 모드 제공
2. 집중 세션 태그 선택
3. 세션 완료 시 간단 리뷰 선택 - 집중 잘됨, 흐트러짐
4. 세션 완료 시 작동할 알림음의 횟수 및 깜빡임 효과 설정 가능
5. 세션 중단 시 중단 사유 선택 - 모드별 사유 상이함

## 기술 Stack 
Tauri + React + Typescript in Vite
